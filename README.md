# Strategy Director for Motorsport Manager

Strategy Director adds a hireable race strategist who can execute an agreed pre-race plan for the player’s drivers: practice, qualifying, tyre strategy, pace, fuel, weather calls, safety-car calls, and undercuts.

## Install

1. Install Unity Mod Manager for Motorsport Manager.
2. Download `StrategyDirector-1.1.0.zip` from the GitHub Release.
3. Extract the `StrategyDirector` folder to `Steam/steamapps/common/Motorsport Manager/Mods/`.
4. Start the game and confirm **Strategy Director** is active in UMM.

## Important

The mod adds a persistent staff role. Back up saves before installing or removing it from an active career. Use the in-game UMM controls to configure director behavior and retain manual takeover capability.

## Build from source

`src/strategy-director/` targets .NET 3.5 and needs locally supplied Motorsport Manager managed assemblies, Unity Mod Manager, and Harmony. Those proprietary game assemblies are not distributed here.
